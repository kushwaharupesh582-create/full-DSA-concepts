# C++ Array and Loop Fundamentals

This repository demonstrates the fundamental concepts of C++ programming, specifically focusing on **Arrays** and **Loops**. It provides a practical look at how to initialize, access, and manipulate data within arrays using different techniques.

---

## 📋 Project Overview
The code covers several core programming topics:

* **Array Initialization:** Defining and populating arrays with integer and character data.
* **Manual Indexing:** Accessing array elements directly using their index position (e.g., `arr[0]`).
* **Looping Techniques:** Utilizing `for` loops to iterate through array elements efficiently.
* **Dynamic User Input:** Capturing input from the user at runtime to fill an array.
* **Memory Calculation:** Using the `sizeof()` operator to determine the memory size of arrays.

---

## 🛠️ Code Logic
The project is organized into three logical sections:

1. **Static Integer Array:** Demonstrates accessing a predefined list of integers both manually and via iteration.
2. **Character Array:** Shows how to store and display characters (vowels) using a `for` loop.
3. **Dynamic Input Array:** Implements a system where the program prompts the user to input values, which are then stored and displayed back to the user.
